The shape of the pipeline

Two tools, split at a clean boundary. Python moves bytes and never transforms them. Everything that changes the meaning of a row happens in dbt, in SQL, in the warehouse.

Two sources of truth, routed on purpose

A source value becomes an OMOP concept by one of two routes, and which route it takes is a design decision rather than a convenience. Demographics come from a small file a human signed off. Clinical codes come from the published vocabulary.

How the real study files actually arrive

The documented route stopped working. The tarball host resolves in DNS but refuses to complete a TCP connection, on both ports, from this network. Ingest now has two fallbacks, and the last one is needed for exactly one file.

What the review settled

Twelve mappings were marked REVIEW and left unbuilt. All twelve are now closed, plus two follow-ups the review surfaced. Nothing in the seed says REVIEW any more.

  • Histology instead of one generic code3,677 rows · 8 concepts Every condition record used to carry the same concept, meaning only "breast cancer". Ductal, lobular, mixed, mucinous, metaplastic and angiosarcoma now each resolve to their own SNOMED disorder. This is the decision that makes the OMOP layer worth querying.
  • Death declined, survival keptNOT_MAPPED METABRIC carries no calendar date of any kind, only intervals, so a death date could only be invented. The mapping is refused with the reason recorded, and survival time is carried as an observation in months instead, for deceased and living patients alike so censored follow-up survives.
  • Concept and value are different questions8,077 rows Coding what a value means does not code what is being observed. Vital status, stage and grade had correct values sitting under an observation concept of 0 until both columns were mapped. Grade then moved to MEASUREMENT, because OMOP routes a row by its concept's domain.
  • Stage, without inventing an edition2,853 rows TCGA names real substages, so those map to AJCC 7th pathological concepts. METABRIC gives bare integers and states neither edition nor whether staging was clinical, so it uses generic stage concepts that assert none of it.
